# 🌐 World Marble

브라우저에서 바로 하는 세계 도시 보드게임. 한 기기에서 2~4명이 돌아가며(사람 또는 컴퓨터) 플레이합니다.
설치·서버 없이 `index.html`을 브라우저로 열면 됩니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 4개 (첫 화면 / 새 게임 설정 / 게임 / 결과) |
| `css/style.css` | 디자인, 맥북·휴대폰 화면 배치 |
| `js/data.js` | **판·도시·통행료·황금열쇠·규칙 숫자** — 밸런스는 여기만 고치면 됩니다 |
| `js/game.js` | 게임 규칙 (주사위, 이동, 사기·짓기·통행료, 무인도, 우주여행, 기금, 파산, 승패) |
| `js/ai.js` | 컴퓨터 플레이어 판단 |
| `js/ui.js` | 게임판 그리기, 애니메이션, 결정 창 |
| `js/main.js` | 화면 전환, 설정, 메뉴, 자동 저장(localStorage) |

## 확인용 테스트 (선택, Node + Playwright 필요)
- `node tests/rules.js` — 규칙 단위 확인
- `node tests/sim.js 5` — 컴퓨터끼리 5판 끝까지 돌려 오류 확인
- `node tests/ui.js` — 맥북·휴대폰 크기 스크린샷을 `shots/`에 저장

`index.html?test=0.3` 처럼 열면 애니메이션 속도를 바꿔 빠르게 볼 수 있습니다.
